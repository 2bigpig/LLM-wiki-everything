# everything界面设计

## 方向

everything是用于收藏、整理和追溯个人知识的工作台。界面采用白色档案纸、石墨文字和蓝色引用，强调冷静、准确与条理。视觉重点来自真实收藏索引和知识图谱；来源编号与引用边线作为一致的识别细节。

保留“everything”名称及现有功能，重新组织页面比例与阅读层级。不用装饰插画、虚构统计、营销头图或外部字体请求填充空白。

## 九轮调整

1. **间距**：以 4px 为基准，侧栏 248px，顶栏 64px，常规页面边距 40px；导航行 36px，卡片内边距 20–28px。
2. **颜色**：用一套中性灰阶维护底色、白色容器和细边框，强调色 `#2854c7`。蓝色用于主操作、选中状态和来源入口；失败与待配置保留低饱和语义色。
3. **图标**：复用原生 SVG 组件，常规图标 18px、描边 1.5，不引入图标依赖。替换装饰星芒和文本勾号，品牌采用引用括号式的平面标记。
4. **文案**：标题直接使用“我的收藏”“知识 Wiki”“整理进度”等页面名称。移除英文大写装饰标签与宣传性口号，保留读取范围、来源版本和失败原因。
5. **字体**：使用本机系统无衬线字体，不依赖联网加载。正文 14–15px、辅助信息 12–13px、标题 28–32px；序号和统计使用等宽数字。
6. **布局**：收藏使用带编号的索引行，右侧只显示实际 Wiki 页数及页面。960px 以下采用菜单导航，完整保留所有入口，详情与设置按阅读顺序堆叠。
7. **细节**：统一边框、8px 控件圆角、12px 容器圆角、状态点和可见焦点环。搜索保留 Ctrl+K；手机导航使用原生 dialog；关闭录入框后恢复触发按钮焦点。
8. **视觉**：图谱读取公共颜色变量，以形状区分收藏、资源、主题和 Wiki。少量节点不会自动放大至整个画布，仍支持手动缩放、拖动和关系列表。
9. **动效**：只保留短暂的颜色与边框变化及真实加载指示，不添加循环装饰、卡片缩放、布局动画或新动效依赖；遵循减少动态效果设置。

## 维护与验收

公共视觉变量与组件样式在 `frontend/src/style.css`。这是视觉样式，不写入部署用 `config.yaml`。图谱 Canvas 从同一组 CSS 变量读取颜色，避免与普通页面脱节。

验收包括桌面/手机的现有收藏、混合输入、截图/拖放、来源重试、Wiki、搜索、图谱时间线和回顾流程，以及全部导航入口、320/768/1024/1440 断点、快捷键、弹窗焦点恢复、菜单 Escape 和主按钮文字 4.5:1 对比度。浏览器使用隔离测试数据；实际页面仅截图检查，不为设计预览写入用户资料。

截图保存在被忽略的 `data/design/`，不进入发布包；前端继续通过 Vite 启动，刷新即可查看，无需迁移数据库或重启模型服务。

本轮验证：12 项桌面/手机浏览器验收全部通过，Vue TypeScript 检查、生产构建、Node 配置测试与 Git 差异格式检查通过。主按钮文字对比度 6.6:1。三轮截图检查覆盖首页、手机菜单、录入、图谱与设置，未发现整页横向溢出或 JavaScript 页面异常。后端、公共部署配置和数据库未改动，没有新增依赖。
