# 模型连接与用途管理

everything 使用 LangChain 独立厂商适配包，模型配置存 PostgreSQL；现有 API/Worker、LangGraph、队列和模型容器保持原架构。

## 首次准备与旧配置升级

先停止正在运行的 API/Worker。数据库和模型容器保持运行。在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-local.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1 -Service migrate
powershell -ExecutionPolicy Bypass -File .\scripts\prepare-model-settings.ps1
powershell -ExecutionPolicy Bypass -File .\scripts\start-backend.ps1
```

准备入口幂等：保留现有数据库密码和实例口令；缺少时生成 `API_TOKEN`、`MODEL_CREDENTIAL_KEY`，保存在根目录 `.env`，不在终端显示值。使用本机编辑器查看 `API_TOKEN`，在设置页输入并验证即可。不要将 `.env` 发给他人。

原 YAML 中 LLM 地址、模型、超时及输出额度配合旧 `LLM_API_KEY` 导入默认连接；成功才从文件移除旧密钥键。没有旧密钥时正常初始化。若密钥存在却缺少模型名称，准备会停止并保留原文件。备份 `.env.backup.models.*` 同样含敏感数据，受 Git 和 Docker 忽略。

凭据用 Fernet 加密保存 PostgreSQL，解密主密钥只在 `.env`。备份数据库时必须另外保管对应 `.env`；丢失主密钥无法恢复厂商凭据。密钥损坏时恢复原值，不能随意生成新值覆盖。

数据库升级到 `0003`，新增模型连接、修订、偏好、探测、向量空间及来源向量表；旧来源与引用 ID 不变，原 BGE 向量导入默认空间。降级使用升级前数据库备份，迁移不会自动删除模型数据。

## 配置在哪里修改

- `config.yaml`：监听、Docker、目录、预算上限、初始参数和厂商预设。更改部署参数需重启相应进程；模型容器参数仍由 YAML 管理。
- 设置页／PostgreSQL：连接地址、模型 ID、密钥、启停、超时、输出上限、阶段分配和当前向量空间。保存后对新任务生效，不要求重启。
- `.env`：数据库密码、实例口令和模型凭据主密钥。`LLM_API_KEY` 仅用于旧配置导入；运行调用不再使用它覆盖数据库配置。

准备脚本生成或修改实例口令、主密钥后，需要重启 API/Worker 一次。前端始终请求项目后端，不直接调用厂商。

## 页面操作

1. 添加连接，选择厂商预设，确认地域、标准 API 地址及对应密钥。国内智谱与国际 Z.AI 是不同连接；不要混用密钥。Azure 地址填写资源端点，模型 ID 填部署名，并配置 API 版本。
2. 添加 LLM 或 Embedding 模型。可读取模型列表，也可手动填模型 ID／火山方舟 endpoint ID。列表读取失败不代表该模型不能调用。预设不承诺每个模型支持全部功能。
3. 主动测试调用、JSON 或向量。测试只使用固定测试文本，不发送收藏正文；可能产生费用，调用和用量记录可查。未测试与测试失败分别展示。
4. 分配默认模型，按需覆写分析、关联、Wiki 和深层回顾；分析分组与合并共用分析绑定。日常站内回顾默认不调用模型。
5. 复制连接只复制公开配置，需要重新填写密钥。停用连接立即阻止后续调用，在途请求可能完成；历史记录仍保留。

设置管理接口必须显式携带实例口令，即使其他 API 在未设置口令时允许本机使用，模型管理也不会开放。表单密钥保存后不回传、不进入浏览器持久化存储；实例口令继续只存在当前浏览器会话。

## 参数修订、重试与预算

### 设置页字段说明

- **本地访问口令**对应根目录 `.env` 中的 `API_TOKEN`，用于访问 everything 和管理模型，不是厂商 API Key。验证后保存在当前浏览器会话中，附件预览另使用八小时 HttpOnly Cookie；清除会话只清除浏览器凭证。
- **模型用量**显示本月 Tokens 与 `config.yaml` 中的项目额度，不是厂商余额或货币账单。异常请求可能已产生费用，最近调用记录可辅助排查。
- **当前整理能力**显示配置是否启用，不代表远程服务健康或已完成能力测试。
- **连接**管理协议、服务地址和厂商 API Key；**模型**管理具体模型 ID 及调用参数，同一连接可以添加多个模型。
- **厂商预设**提供默认地址和协议；**连接名称**与**模型名称**供自己辨认，**模型 ID**必须填写实际模型名或部署 ID。更换地址或协议需要重新填写密钥，本地免密连接可显式留空。
- **类型**选择 LLM 或 Embedding；前者分析和生成内容，后者生成检索向量。
- **超时**限制单次调用等待时间，**最大输出 Tokens**限制单次回复长度，两者都不是月度额度。
- **Temperature**控制随机性，留空使用厂商默认；**思考模式**要求模型支持对应推理参数；**Azure API 版本**只用于 Azure 协议。
- **读取模型列表**失败时仍可手填 ID；**测试调用**检查基础响应，**测试 JSON**检查结构化输出，**测试向量**检查返回向量与 1024 维约束。测试可能产生费用，配置保存本身不会联网测试。
- **用途分配**中，分析与综合提取摘要、要点和主题，内容关联解释新旧资料联系，Wiki 生成维护知识页，深层回顾按需生成深入解释。未覆写的阶段使用默认模型；基础每日回顾不额外调用 LLM。
- **向量索引**用于语义检索，更换模型需准备独立空间、重建并确认切换。重建／补齐只处理缺失片段，取消后可恢复，旧空间可用于回退；继续使用当前 BGE-M3 时无需重建。

日常最简配置路径：验证口令 → 添加连接 → 添加 LLM → 测试 JSON → 分配默认模型。

### 配置生效与用量

修改模型参数产生不可变修订，新任务固定各阶段修订；自动重试和“继续处理”沿用已有修订，主动“重新分析”采用当前配置。原先未配置的阶段允许首次补配恢复，不改动已固定阶段。

同一目标的 API Key 可轮换，后续请求读取新密钥。修改地址或协议必须显式替换密钥（免密服务填空），原任务停止使用旧目标，需要重新保存模型并重新分析。不会携带密钥跨地址重定向。

各 SDK 自动重试关闭，任务重试由现有队列管理，不自动跨厂商 fallback。调用记录包含连接、修订、用途和实际或保守预留用量，JSON 校验失败也记录已发生用量。厂商不返回 usage 时保留估算，Token 额度不是货币账单。云端向量及测试计入总额度，本地 BGE 记录调用但不计云端 Token。

兼容协议的思考参数按厂商约定传递，Claude/Google 使用各自协议。不同模型参数约束不同，不支持时明确失败，不静默删除参数；Claude 启用思考时输出上限需大于 1024。

## 1024 维向量空间

本轮只接受 1024 个有限数值，不能截断、补零或混用同维度的不同模型。不自动替云厂商降维；选择原生支持 1024 维输出的模型或服务。Google Embedding 请求显式使用其输出维度参数；厂商仍需实际支持。

修改 Embedding 模型后，准备新空间，点击重建。现有 Worker 分批生成缺失来源向量；中断、取消、失败不会清空旧结果，可恢复重建。旧空间继续提供检索。

点击切换需确认；有缺失来源时先补齐，完成后再激活。保留旧空间用于回退，回退前也会补齐缺失来源。来源版本、归档过滤和重复原文去重规则不变。向量服务故障或预算不足时搜索降级为关键词并提示，原始资料、分析和 Wiki 不因此丢失。

## 排错

- 管理页提示准备：确认已迁移，执行准备脚本，重启后端并验证 `.env` 的实例口令。
- 解密失败：恢复对应主密钥，不要覆盖；检查是否用错了配置目录。
- 等待配置：检查默认／阶段绑定、模型与连接是否启用，以及目标地址是否修改后尚未重新保存模型。
- JSON 测试失败：更换支持 JSON 的模型，检查思考模式、输出长度和厂商支持范围。
- 读取列表失败：使用手动模型 ID；某些兼容服务没有 `/models`，Azure 的部署发现也可能需要额外权限。
- 向量失败：先运行向量测试，确认模型、1024 维、余额和调用额度；检查 Worker 是否启动。未启动 Worker 时重建保留在排队状态。
- 使用调用记录中的连接、修订和用途定位问题；终端/API/Worker 日志保留类型和请求 ID，不输出密钥和资料正文。
